# New-DscResourceInstance

## SYNOPSIS

Creates a DSC resource instance from a type name and properties.

## SYNTAX

```powershell
New-DscResourceInstance [-Type] <string> [-Instance <psobject>] [-Properties <hashtable>] [<CommonParameters>]
```

## DESCRIPTION

Creates a `DscResourceInstanceInfo` object that pairs a DSC resource type with
its desired-state properties. Properties can be supplied as a hashtable or
extracted from a typed object (e.g., a `DSC.*` type generated by
`Import-DscResourceType`).

The resulting object can be passed to `Add-DscResourceInstance` via the
`-Instance` parameter.

## EXAMPLES

### Example 1 - Create an instance from a hashtable

```powershell
$instance = New-DscResourceInstance -Type 'OpenDsc.Windows/Service' -Properties @{
    name   = 'sshd'
    status = 'Running'
}
```

Creates a resource instance with properties from a hashtable.

### Example 2 - Create an instance from a typed object

```powershell
Import-DscResourceType -Type 'OpenDsc.Windows/Service'
$svc = [DSC.OpenDsc.Windows.Service]@{ Name = 'sshd'; Status = 'Running' }
$instance = $svc | New-DscResourceInstance -Type 'OpenDsc.Windows/Service'
```

Uses a generated `DSC.*` type piped as the `-Instance` parameter.

### Example 3 - Add the instance to a configuration

```powershell
$instance = New-DscResourceInstance -Type 'OpenDsc.Windows/Service' -Properties @{
    name   = 'sshd'
    status = 'Running'
}
$config = New-DscConfiguration
$config | Add-DscResourceInstance -Name 'SSHD' -Instance $instance
```

Creates an instance and adds it to a configuration builder.

## INPUTS

### System.Management.Automation.PSObject

A typed or untyped object whose properties are extracted as resource properties.

## OUTPUTS

### OpenDsc.Authoring.Commands.DscResourceInstanceInfo

An object containing the resource type and properties dictionary.

## NOTES

Either `-Instance` or `-Properties` must be specified, but not both.
